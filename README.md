# House Price Prediction System

## Project Overview

This project is an end-to-end machine learning system that predicts house prices using regression models.

It includes:

- data cleaning
- exploratory data analysis
- feature engineering
- preprocessing pipeline
- model training
- model evaluation
- FastAPI backend
- Streamlit dashboard
- GitHub-ready project structure

---

## Problem Statement

Manual house price estimation can be inaccurate because property prices depend on many factors such as area, bedrooms, bathrooms, parking, furnishing status, location preference, and available facilities.

This project solves the problem by using machine learning regression models to predict house prices based on property features.
